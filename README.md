# Rithub

Local-first time & energy tracker — per-project timers, text-only weekly reports, gym log with double-progression engine, zero backend.

```
Rithub/
├── index.html   # tracker: projects, timers, commits
├── app.js       # tracker logic (localStorage rithub-v2, gist sync)
├── style.css    # courier on paper UI
├── report.html  # weekly text report
├── report.js    # report views: energy curve, timeline, gaps, balance, deep-water rate
├── gym.html     # gym log: PPL logging, progress, month goals, settings
├── gym.js       # double-progression suggestion engine (localStorage rithub-gym-v1)
└── README.md    # this file
```
